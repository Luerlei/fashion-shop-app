# 时尚购物 - 移动端电商APP原型

一个专注于时尚服饰的移动购物应用原型，使用纯HTML+CSS实现。

## 页面展示

包含5个核心页面：
- **首页** - 商品推荐、分类入口、搜索功能
- **分类页** - 商品分类浏览、筛选
- **商品详情页** - 商品展示、规格选择、加购/立即购买
- **购物车页** - 已选商品列表、数量修改、结算
- **我的页面** - 用户中心、订单入口、设置

## 技术栈

- HTML5
- CSS3
- 内联SVG图标
- 响应式设计（375px移动端标准）

## 使用方法

直接在浏览器中打开 `index.html` 即可预览所有页面原型。

## 设计特点

- 珊瑚红主色调，简约现代风格
- iPhone标准移动端尺寸
- 底部Tab导航栏
- 卡片式布局
